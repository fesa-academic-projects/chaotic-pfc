# Security policy

## Supported versions

Only the latest released version receives security fixes.

| Version | Supported          |
| ------- | ------------------ |
| 0.8.x   | :white_check_mark: |
| < 0.8   | :x:                |

## Reporting a vulnerability

Please **do not** open a public issue for a security problem. Report it
privately using GitHub's
[security advisories](https://github.com/fesa-academic-projects/chaotic-pfc/security/advisories/new)
("Report a vulnerability"), or by e-mail to a maintainer listed in
[AUTHORS](AUTHORS).

Include, as far as possible:

- a description of the issue and its impact;
- the affected version(s) and platform;
- a minimal reproduction;
- any suggested fix or mitigation.

We aim to acknowledge a report within a few days, keep you informed while we
investigate, and publish a fix together with an advisory (crediting the reporter
unless you prefer otherwise) once it is available.
